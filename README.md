# Distribusion — removal request honored

Distribusion asked to be removed from the APIs.io catalog on **2026-08-17**, and the
request was honored the same day. This repository is kept only so that inbound links to
this URL do not dangle.

## What they asked for

> "Our API documentation (distribusion) was indexed on your website, can you please remove
> it as soon as possible?"

— via issue #10 on `github.com/api-search/inbox`

## What was removed

Everything the request was about:

- the `apis.yml` index and the Distribusion Retailer API record
- the pointer to `docs.distribusion.com`
- the conformance, llms, MCP, security and screenshot artifacts
- the Kin Score and Agent Readiness score, and all score history
- every tag, industry, country, region and index membership

## What remains

APIs.io keeps a **minimal, unrated** record: the company name, a neutral description, and
a link to Distribusion's own website. Nothing about their API surface, and **no rating** —
the page says Unrated. That a company exists, and where its own website is, is a plain
fact about the public web.

Distribusion is on the permanent delisting registry, which every pipeline in the network
consults before it can create, enrich, score or index a provider. That entry — not the
deletion of these files — is what keeps a future harvest or re-crawl from re-adding them.

## Removal requests generally

If you represent a company listed in this catalog and want to be removed, email
kin@apievangelist.com. Removal is honored on request and at no charge — no proof of
standing required.

— Kin Lane, API Evangelist · 2026-08-17
